## Why This Prompt Works

The prompt is structured to prevent the most common Replit AI failure modes:

- **Architecture context first** — the agent knows what already exists so it doesn't rewrite working TRON code 
- **Exact flow specification** — the 5-step gasless relay flow is explicit enough that the agent can't guess wrong on the feePayer pattern 
- **Exact mint addresses and constants** — eliminates hallucination risk on the USDC mint (`EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v`) 
- **"What NOT to change" section** — Replit agents often over-edit; this constrains scope explicitly
- **Ordered implementation steps** — gives the agent a dependency-safe build sequence (constants → utility → API → UI), which reduces mid-build breakage
- **ATA cost tracking** — included so the agent doesn't silently skip the $0.30/new-user sponsor cost that could drain your sponsor wallet without visibility 
- **Security instruction on relay endpoint** — the instruction to validate the transaction contains only one SPL transfer prevents a user from submitting a malicious tx for the sponsor to sign 

You may want to also tell Replit: *"After completing step 4 (the relay endpoint), pause and show me the relay endpoint code before continuing"* — this lets you catch any security issues in the most sensitive piece before the UI is built on top of it.
