# Utopia API Client Reference

API URL endpoint: http(s)://127.0.0.1:port number/api/1.0

API allows creating services that directly interact with the ecosystem of Utopia. It significantly extends the capabilities of users and developers to implement the anonymous and secure solutions on the network.

See the list of available methods at the left side.

# How to receive finance notifications using http post

Add command line param (--notificationCallback=your\_url) to the utopia. For example "utopia.exe --notificationCallback=https://127.0.0.1:3000/post-endpoint"

As optional you can add notificationCallback into the messenger.ini file.

After this, you will receive all notifications about incoming transactions. If you want to receive only certain types of transactions, add the 'notificationCallbackFilter', parameter with values: "all", "transfer","voucher","invoice","uns","other". You can speficy one of them, or several types.

For example: utopia.exe --notificationCallback=https://127.0.0.1:3000/post-endpoint --notificationCallbackFilter="voucher,uns"
